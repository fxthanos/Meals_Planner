# مخطط الوجبات

تطبيق ويب عربي لتكوين خطط وجبات ضمن نطاق تكلفة وقواعد قابلة للضبط. ينشئ التطبيق وجبات من كتالوج المكونات، يتحقق من القيود بعد كل تعديل، ويحفظ العمل محليًا في المتصفح.

## ما الذي يقدمه؟

- توليد خطة وجبات تعتمد على عدد الوجبات، حد المكونات، نطاق التكلفة، والمتوسط المستهدف.
- كتالوج قابل للتحرير للمكونات والأسعار والوحدات والتصنيفات والعائلات والوسوم.
- تحقق فوري من الوجبة والخطة مع سجل للنتائج والمخالفات.
- قواعد مدمجة للتكوين، التغطية، الشيبسي، الخبز والفطير، مجموعات الاستبعاد، السلطة والخيار، جبنة المثلثات، الطحينة، التكلفة، والتوازن الغذائي.
- قواعد مخصصة: مجموعة استبعاد، منع ثنائي، منع شرطي، إلزام شرطي، وسماح مشروط.
- بروفايلات تحفظ نسخة من الإعدادات لاستعادتها لاحقًا.
- استيراد وتصدير JSON للخطة والإعدادات والبروفايلات، وطباعة الخطة أو حفظها PDF من نافذة الطباعة.

## التشغيل

لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم. افتح `index.html` مباشرة في متصفح حديث يدعم JavaScript و`localStorage`.

للتشغيل من خادم محلي اختياري، إن كان Python متاحًا:

```powershell
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## طريقة الاستخدام

1. افتح **كتالوج المكونات** وعدّل الأسعار أو التصنيفات أو أضف مكونات عند الحاجة.
2. افتح **الإعدادات** لضبط عدد الوجبات، التكاليف، القيود، حدود الاستخدام، أو القواعد المخصصة.
3. من **لوحة التحكم** اختر **توليد الوجبات**.
4. راجع التفاصيل في **الوجبات** وعدّل المكونات أو الكميات؛ يعيد التطبيق التحقق ويسجل النتيجة.
5. راجع **سجل التحقق**، ثم صدّر الخطة أو اطبعها عند الحاجة.

## البيانات والخصوصية

لا يتصل التطبيق بخدمة خلفية ولا بقاعدة بيانات. تُحفظ البيانات في `localStorage` ضمن المتصفح الحالي بالمفاتيح التالية:

- `mealsPlanner.state.v2`: الكتالوج والوجبات وسجل التحقق وتعديلات الأسعار.
- `mealsPlanner.config.v5`: الإعدادات والقواعد.
- `mealsPlanner.profiles.v1`: البروفايلات المحفوظة.

استخدم زر **تصدير** قبل مسح بيانات المتصفح أو الانتقال إلى جهاز آخر. تؤدي **إعادة التعيين الشاملة** إلى حذف هذه البيانات المحلية.

## القيم الأولية

يبدأ التطبيق بكتالوج من 33 مكوّنًا وخطة فارغة. الإعدادات الأولية تطلب 12 وجبة، بحد أدنى 7 مكونات لكل وجبة، مع تفعيل تغطية المكونات والقواعد المدمجة. يمكن تغيير جميع هذه القيم من شاشة الإعدادات.


## المعمارية

تُحمَّل السكربتات بالترتيب `state.js` ثم `render.js` ثم `app.js`. عند بدء التطبيق تُحمَّل الإعدادات والحالة والكتالوج والبروفايلات، ثم تُرسم الشاشة وفق مسار الرابط مثل `#/dashboard` أو `#/catalog`.

- `Generation` ينشئ محاولات خطة من بذرة قابلة للضبط ويراعي القيود أثناء إضافة المكونات.
- `Validation` يفحص كل وجبة والخطة الكاملة، ويحسب التكلفة والتغطية والانحراف عن الهدف.
- `Config` و`Catalog` و`State` و`Profiles` تدير نموذج البيانات والحفظ المحلي.
- `Renderer` و`UI` و`Modals` تنشئ الواجهات والتنبيهات والنوافذ المنبثقة.

للمخطط المرئي افتح [عرض المعمارية](architecture-view.html) أو [ملف SVG](architecture.svg). يوجد المصدر الكامل في [architecture.dot](architecture.dot).
